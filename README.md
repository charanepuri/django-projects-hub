## 🛠️ Built With

- **HTML5**: Semantic and accessible document structure.
- **CSS3**: Custom dark Django palette (`#0c4b33`, `#44b78b`), glassmorphism cards, gradients, and micro-interactions.
- **JavaScript (Vanilla ES6+)**: Dynamic card rendering, live keyword filtering, and safe string sanitization.
- **Bootstrap 5.3.3**: Responsive mobile-first grid system, navbars, and utilities.
- **Bootstrap Icons**: Lightweight SVG icon pack for tech and social elements.

## 📂 Project Structure

```text
Django Projects Hub/
├── index.html                 # Main web application entry point

├── script.js                  # Dynamic project catalog, live search, and rendering
```
